# 第7章 死者的旋律

查一首歌的来历，在我们这行有固定的路子：唱片内页、著作权登记、业界数据库，最后才是人。周二上午，我推掉了两个约，把《深绿の影》这条路子从头走了一遍。

先说歌本身。它不是 Velvet Note 的原创曲。流媒体页面上的信息写得很清楚：词曲，ミドリ。原唱，ミドリ。单名，没有姓氏，是艺名的写法。收录于七年多前的一张迷你专辑，发行方是一家已经不存在的独立厂牌。专辑的封面是深绿色的底，一株植物的剪影，设计者署名也是同一个名字。那张专辑在乐迷圈子里小有名气，但在任何畅销榜上都没有出现过，属于那种被一小撮人反复提起、被大多数人错过的唱片。

然后是著作权。登记记录是公开的，JASRAC 的作品数据库 J-WID，谁都可以查，我查了。《深绿の影》的词曲著作权，曲作者栏登记的是「ミドリ」，管理登记在「株式会社音羽制作」名下，那是早川弦吾九十年代的个人公司，管理契约的签约人栏里，是一个我此刻已经熟悉的名字：早川弦吾。登记日期在专辑发行之前。也就是说，这首歌从诞生起，法上的收益流向就不是写出它的人，而是她当时的制作人。

音羽制作是早川九十年代做制作人时的个人公司，早已停业，但著作权不随公司停业而消灭，它跟着管理人走。我又查了版税的分配惯例，找了一个在著作权管理团体做事的熟人，让他按行规估了一下：这种登记的形态下，原作者能拿到的部分，接近于零。

「圈内这种合同多吗？」我问。

「多。尤其是新人，尤其是独立厂牌。」熟人在电话里说，「歌手签的时候不懂，懂了的时候歌已经不是自己的了。你问的是哪一首？」

我报了曲名和歌手的名字。电话那头停了几秒。

「ミドリ啊。」他说，「那是个可惜的人。嗓子不差，写的东西比嗓子还好，就是命不好，签错了人。这个圈子里，签错一次人，一辈子就给别人打工了。」

我没有追问。这类行内的惋惜听得多了，我应了两句，便把话题转回登记的细节。

ミドリ。这个名字的生平，不是从哪一页年表上读来的，是我用周二下午和周三上午，一段一段捡回来的。第一段来自旧报纸音乐栏的讣闻栏角，豆腐块大小：创作歌手ミドリ，二十六岁那年的春天，在自己租住的公寓里去世，警方按自杀结案，没有他杀嫌疑。没有遗书公开，没有沸沸扬扬的报道。第二段来自旧论坛的截图，我存了七八张：当年的现场工作人员回忆录音期间她与制作人的关系，用词从「严苛」到「不像话」不等。第三段来自东京近郊一家地方报纸的旧报道，文化栏的边角，写本地出身的歌手：她出身八王子市，十九岁开始在小剧场唱歌，二十二岁被早川弦吾签下，二十四岁出那张迷你专辑，反响在小圈子里很好，公开活动却越来越少。

关于她的死，旧帖里反复出现的一个说法是「被榨干了」。工作排到过密，版税拿不到，歌的署名权在法律上属于别人。这类帖子的情绪很重，事实的密度不高，我按行规打了折扣。但有两条信息相互独立、出处不同，我不能当没看见：一，她生前最后半年多次向身边人提过「想把歌拿回来」；二，她去世后，《深绿の影》的著作权登记没有变过，七年间这首歌在流媒体上、在别的歌手的翻唱里持续产生收益，收益的流向始终是早川弦吾。

一个人死了，她的歌还活着，养活的是她恨过的人。这种结构在音乐产业里不新鲜，新鲜的是它此刻和一桩杀人案住在同一条时间线里。写歌的人不是铃，另有其人，而且已经死了七年；听歌的人死了一个；收钱的那个，七年前就该收手了。这条线此刻还接不到案子上，这一点我清楚，但它是早川弦吾这个人的履历上擦不掉的一行。

周三下午，我把这些材料摊在桌上，拍照，归档，写了一份给编辑的备忘录。备忘录用的是给外行看的写法，我把「著作邻接权」「管理契约」这类词都换成了人话。写到收益结构那一节，我自己也停了一下：一首歌七年间持续挣到的钱，数字不算惊人，但足够让一个人在另一个人的账本上永远抬不起头。

找唱片费了一番功夫。银座的老唱片行我跑了三家。第一家在并木通的地下室，店主听完曲名，从柜台下面抽出一张价目表，指着上面一行手写的字：事件之后，这张盘的问价一天一个数，店里最后一张上周被人买走。第二家在晴海通背后的楼里，专营独立厂牌，墙上贴着九十年代的演出海报，店主是个寡言的中年人，他说这张盘他当年进过十张，卖了两年。「她本人来过店里一次，签售，没人排队。」他说，「那天签了三张。我留了一张自己听。」第三家连锁店的系统里干脆查无此盘，店员是个年轻人，好心建议我去网上找。网上的价格已经是原价的四倍，卖家备注写着「事件关联盘」，库存两件。

一张唱片因为人的死涨了四倍。我把来路记进备忘录，回头连同版税的事一并写进稿子。

外面的网络没有这份迟疑。「杀人歌谣模仿犯」的论调在周二、周三两天里完成了升级，升级的关键正是歌词卡。

有人指出了那张卡的「序数」：「深く沈め、夜の底へ」，第二首《水底の子守歌》。第一晚，第一桩杀人，对应的是第二首？争论很快达成了猎奇式的共识：凶手在按歌单行动，顺序也许从某一首起算，也许有错位的规则，但方向是确定的——歌单就是行凶清单。一个粉丝几十万的账号把这个推断做成了一张图，八首曲目列成一列，第二首后面打了一个红色的勾。图的配文只有一行字：

「按歌单顺序，还会有人死。下一个该轮到第 3 曲。」

第 3 曲，《鉄の聖母》。九分钟，讲的是昭和年间一个用铁器杀人的案子。帖子下面，对「下一起手法」的猜测盖了几百楼，转发过了万。另一拨人开始点名：铃的下一场演出、乐队成员、店里的常客，凡是和那张歌单有关系的活人，都被这份图清单式地扫了一遍。

警方不可能不反应。周三晚上，银座七丁目一带的巡逻密度肉眼可见地加了上去，数寄屋桥方向的地铁站口有了穿制服的岗。我在中央通的咖啡馆里亲耳听见邻桌两个白领讨论「最近晚上别走小路」。银座这个街区对恐慌的消化能力很强，但再强的消化能力也架不住一张有八个条目的清单，尤其当清单的第一项已经兑了现。

我给牛込打了个电话，问模仿犯这条线警方怎么看。他的回答很短：「网上的话，一句都不进我们的白板。」顿了顿，又补了一句，「但巡逻不能不加。这是两回事。」

我懂他的意思，没再多问。巡逻的事，轮不到我一个写稿的插嘴。

电话里我顺口问了一句奈仓铃的近况。牛込说，她照常配合调查，警方建议她暂停近期所有的公开演出，她接受了。「她说了一件事。」牛込的语气难得地缓了一点，「她说，那八首歌现在她一首都不敢再开口。不是怕，是觉得对不起歌。」

对不起歌。我挂了电话，把这三个字记在了本子上，在旁边重重画了一个圈。

周四，雨。银座的雨落在霓虹灯上，整条街像浸在显影液里。第三曲的帖子还在发酵，又有两家店被网民「对号入座」，店家忙着出来澄清。

可我站在雨里想的是另一件事。八首歌，一张歌单，一具尸体，一句歌词。歌谣正在从舞台上走下来，走进新闻，走进巡逻警察的路线图，走进两个白领的对话里。写歌的人死了七年，唱歌的人还在台上，听歌的人死了一个，而歌本身被一只看不见的手拿着，在各个解释之间递来递去。

那天傍晚我回公寓，把ミドリ那张迷你专辑找了出来。二手网站上周三下单的，已经涨到原价的四倍，卖家备注「事件关联盘」。我把《深绿の影》放了四遍。铃的现场版重，原唱轻，轻得几乎浮在编曲上面，咬字却一字不让。副歌弱下来又撑住的那个地方，原唱的处理和铃不一样，铃是硬撑，ミドリ是让它自然落下去再拾起来。第四遍放到一半，我把音响关了。

房间里静下来的时候，我脑子里还是那个名字。ミドリ。ミドリ。

我打开电脑，在搜索框里打下了「ミドリ　家族」几个字，又删掉了。当时替我删除它的理由很体面：死者的家属不该被无关的好奇打扰。这个理由到今天也是对的。错的是另一件事——我应该在敲下那几个字之前，先问自己一个问题：为什么这个名字让我停笔。她二十六岁就停了，她的歌还在替别人挣钱，这两个事实摆在一起，本身就是一桩没有结案的案子。可它和我手头的这桩，中间隔着什么，我说不出来。

当时的我没有答案。光标在空白的搜索框里一闪，一闪。

我合上电脑，在备忘录里给自己列了明天的三件事。一，找那家厂牌当年的人，厂牌没了，做过经纪人、跑过宣传的人总还在这个圈子里。二，找ミドリ的旧友，旧帖里有几个 ID 当年和她走得很近，语气不是路人。三，托出版社的朋友翻东京近郊地方版的旧报道，小报的地方栏有时候比大报记得多。家属我不去碰，这是我的底线，但这些绕开家属的路，每一条都走得通。
