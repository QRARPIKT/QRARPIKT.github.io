# 专家D报告 · 《过拟合》对抗性提前破解外审

立场声明：我不是普通读者。我拿着"打败这本书"的目标读，每个章末做三件事：更新嫌疑人排序、更新机制猜测、揣测作者的叙事诡计。以下日志按真实初读顺序记录，不以后见之明粉饰。

---

## 第一阶段：逐章破解日志

### ch1 结
- 嫌疑人：无个人名单。框架性警惕对象：任何"即将被请进办案圈的外人"。
- 机制猜测：遗体被摆姿、教具结被用在手腕、现场零遗留 → 预谋 + 展示型犯罪。三件物（窗、尸斑、结）各自完整互不挨着 → 凶手在造"意义"，不在遮掩。
- 作者揣测：〔顾问工作记录·01〕在顾问登场前就出现了。"样本量小，逐项可复核"——这不是警方口径，是观察者口径。第一章末我就记下：这本书有一个身份不明的记录者，而他记录的是现场勘查。记录者装置 = 本书最大的叙事层伏笔，很可能就是凶手本人。

### ch2 菲尔兹
- 嫌疑人：暂无个人，但聘任记录上"横平竖直"的签名被单独给了一句——物件级伏笔，入册。
- 机制：中村"用右手"的十年习惯被反复强调 → 结的仿造必然涉及手性/手法细节，凶手必是见过教具原件的圈内人。
- 作者揣测：记录02 给松枝建档（"档案建立。后续按事件更新"）。警方不会给自家顾问建这种带评价的档（"上升轨迹自本科起为直线"）。这是实验者对实验对象建档。记录者 = 凶手，且与数据/学界相关 —— ch2 末我已把这个工作假设立起来了。

### ch3 清洗 ★关键章
- 嫌疑人排序：**早川渉（首位，此后未再让位）**。理由：①"研究室出身的学长、警方数据顾问、由松枝背书引进"——类型定式：侦探亲手担保的人是凶手；②他是唯一站在名单外却将握住全部名单的人。
- 机制猜测：**215→216 编辑事件当场标记**。黄底离群行 + 敲完保存后"多停了一秒" + 记录03"剔除离群记录一条（……已更正）"三重盖章。一次合法、留痕、见证人在场的改动被作者用句号级篇幅供起来——这是埋点。佐藤実这个名字随之入册（黄旗）。
- 作者揣测：作者在玩"程序正义的犯罪"——犯罪不靠谎言，靠规矩本身。"不问清楚不动手，这是规矩"这句话将来会变成不在场证明。

### ch4 琼斯
- 嫌疑人：早川（不变）。他是唯一同时满足"认得教具 + 算准松枝第一眼会认成教具"的人。
- 机制：祖母结仿方结坐实。凶手连侦探的反应都设计了 → 整个案件是给松枝一个人写的信。
- 作者揣测：记录04 末句"做这枚结的人知道我们在看什么。值得记录。"——记录者公开与"我们"对位。记录者 = 凶手侧，再确认。本章炫技（琼斯多项式）之外的真实功能：确立"结是留言，读者只能是做数学的人"。

### ch5 讲座
- 嫌疑人：早川嫌疑上升。"星座不是天空的事实，是观察者的事实"= 全书题眼，凶手当众把作案哲学念给侦探听。三个坑（数据挖掘偏差/回测幻觉/故事的税）= 松枝后面要逐个踩的坑的预告。
- 机制：无新增，但"作废记录比上线记录多是健康团队的标志"反向成立：本案将没有任何"作废记录"，太顺。
- 作者揣测：这是作者给读者的公平警告章——答案已经念给你听了，看你自己信不信自己的耳朵。"公开场次保留全文存档"这句也是伏笔：这句话将来要被翻出来当呈堂证供。

### ch6 手性
- 嫌疑人：范围收窄到讨论班旧人。松枝自己说出"他甚至可能知道看懂它需要琼斯多项式"→ 凶手预判了松枝的方法论 → 凶手是看着松枝做数学长大的人。活着登场的讨论班旧人只有早川一个。
- 机制：结是口信，读者唯一。案件 = 对话。
- 作者揣测：凶手不会被监控/门禁抓住，他是"合法地站在所有门里面"的人（此判断 ch23 被逐字兑现）。

### ch7 空洞
- 嫌疑人：早川 ~80%。记录06 混入第一人称悼词："老师最后一版批注改得很细。报告没能写完，很遗憾。"——课题善后是早川办的，只有他能写这句。**推论：全部工作记录 = 早川所写 → ch2 给松枝建档的就是他。** 凶手从 ch1 起就在给侦探写观察日志。
- 机制：教具原件下落不明——将来必是情感道具或定罪缺口。
- 作者揣测：本书的第二层文体（倒叙侦探/howcatchem 混血）正式浮出：读者的悬念不是"是谁"，是"看他怎么被看见"。

### ch8 太干净
- 嫌疑人：不变。
- 机制："太干净"= 过拟合的文学说法：无残差 = 模型把数据背下来了。"名单37人是地图还是围墙"——对抗性读法：围墙，凶手在墙外，就是修墙的人自己。
- 作者揣测：记录07"本案例异常洁净"= 凶手在验收自己的作品。作者开始让凶手的记录和松枝的白板写同一句话（ch24 会回收"这个词是你们先说出来的"）。

### ch9 序列 ★
- 嫌疑人：早川 ~90%。**5/15 他以"数据合作"拜访高野的研究所，案发是 5/16 深夜**——登记在册的"无嫌疑拜访"= 踩点。顾问身份 = 进入每个现场的通行证。
- 机制：值夜进出无登记 + 早川白天踩点 → 要么有暗门，要么有第二双手（执行者）。记下此疑。
- 作者揣测：记录08"序列性显著"是凶手给自己的作品打分。媒体"连环"命名是作者故意放的噪声。

### ch10 雏形
- 嫌疑人：早川 90%+。6/6 深夜电话，序列由早川命名（A002863）——凶手帮侦探接上了自己布的线。
- 机制：**名单六人 = 165×1..6，六个连续倍数**。一份人事数据长成等差数列的样子——数据集本身就是作品。佐藤 825=165×5、职工号 216 入名单第四行。
- 作者揣测：整套理论是凶手喂给松枝的模型；记录09"假说可检验。检验窗口：6/19起，逐日"是操盘手的排期表口吻。"共享流程 T+2，合规"——凶手读理论的时间被作者特意留痕（ch24 回收）。

### ch11 持仓 ★（佐藤情感章）
- 嫌疑人：不变。
- 机制：佐藤被写成全书最具体的活人（四百块钱、双手接名片、隔布料按一下、码书推齐）。类型逻辑：**情感重量全部押在名单第四行 → 第四行才是真正的死者**。此时我第一次写下猜测：佐藤会死，且死法将是"被理论判出局之后"。
- 作者揣测：记录10 把保护名单叫"持仓"。凶手用交易术语称呼杀人计划。伊达"最怕普通人上案卷"是作者立的flag。

### ch12 预测
- 嫌疑人：早川 95%。
- 机制：年表读法（师/同届/竞者）一出，对抗性读者立刻看穿：**这正是"观察者的事实"——凶手算准松枝会把自己的履历投射到数据上**。松枝以为读出了凶手的语言，实际是凶手用他的自传当语法。排序键用公开日程 = 凶手把时刻表同时交给学界和松枝。
- 作者揣测：记录11"方向值得下注。市场不一定奖励正确，但市场会惩罚运气差。"——下注者口吻 = 早川行话。工作记录的批注口吻开始从"验收"滑向"操盘"。

### ch13 命中 ★（笔迹并案点）
- 嫌疑人：**早川 = 凶手，对我而言自此是既成事实（97%）**。白板"行距太平、长横的起收笔、站在离板面一步开外正对整块板"= 板书 → 直接对上 ch2/ch3/ch10 三次写到的早川签名"横平竖直"。笔迹并案完成。
- 机制：判别式 = 0 被松枝忽略——记下：退化曲线必有大用（mod 199 的 199 恰在书名里，作者不会浪费它）。唯一未解：前两案的物理执行（早川 5/15 已离开研究所）→ 执行者假说保留。
- 作者揣测：记录12"比对结论：命中"是实验记录口吻。媒体把松枝写成"算出下一个死者的人"= 凶手需要的扩音器。

### ch14 并肩 ★★（我锁定凶手的章）
- 嫌疑人：**锁定。"机器看着呢"——早川用流程担保；对抗性读法：机器就是他自己。**"输入变了"= 他在管理松枝的输入。
- 机制：165 泄露事件收口太快、太顺（"爱说话的人被处分，消息出口收紧"）——揣测：165 是故意放出去的，给将来某样东西预备读者（那张纸，ch15 兑现）。
- 作者揣测：**记录13"他的拟合速率高于预期"——全书第一次，记录里出现对松枝的测量语。被测对象是松枝，测量者是写记录的人 = 早川。这是凶手实验日志的半句自白。** 此刻起，我读这本书的方式从"猜凶手"切换为"观察凶手观察侦探"。

### ch15 噪声 ★（那张纸）
- 嫌疑人：不变。
- 机制：三浦案味型全反（"办事"不是"表演"）。那张纸：钉在签名的位置、不是签名的内容；165 虽已见报，但"答案是 16、16 躺在第四个位置"这个层次超出晚报读者水平——**松枝的"模仿犯"判词太便宜，我当场不采纳**。纸 = 真凶手所放，功能待解（后证实 = 说明书）。三浦"想收手"+ 未发出的草稿 = 将被灭口；**猜测成形：三浦 = 前两案的执行手，本案 = 凶手拆桥**。
- 作者揣测：佐藤/林/小島三个窗口全过无事——理论开始空转，空转的理论需要一个新事实，而名单上只剩一个没有"被守住的价值"的人。

### ch16 排除
- 嫌疑人：不变。
- 机制：松枝五条排除条条站得住——这正是过拟合：**用凶手写的规则，剔除凶手的第四案**。排除意见是松枝替凶手签的第二份文件（第一份是 ch3 对清洗日志的默许）。
- 作者揣测：伊达"最怕顺"+ 便签赌约 = 作者立的对赌协议，ch22 必兑付。记录15"剔除决策合理"= 凶手批改松枝的作业。

### ch17 嘲意
- 嫌疑人：不变。
- 机制：秋季日程全在十月后 → 佐藤成为"无窗口的人"；而理论需要新事实。下一个事实只能是佐藤之死。
- 作者揣测：记录16"市场为叙事付的钱"+ 食堂对话 = 凶手当面点评松枝刚签的排除意见（叙事=理论，事实=三浦）。作者开始让凶手隔着一层纸直接嘲笑侦探，读者能看出、松枝不能——反讽密度升高。

### ch18 精化 ★★★（全书最大可提前破解点）
- 嫌疑人：不变（已无上升空间）。
- 机制：**本章给了对抗性读者全部弹药，足以提前四章破解 ch22 的"大锤"**：松枝白纸黑字写出轨道 x(nM) = 97, 6, 152, **16**, 42, 110；职工号 mod 199：佐藤 216 → 17，无点，剔除。**读者当场两步验算：① 第四格 x=16，ch15 那张纸的答案 = 16；② 佐藤的原始编号 215 mod 199 = 16 —— 第四格本来是佐藤的。** 只要记得 ch3 的 215（"多停了一秒"保证你记得），ch18 章末读者已经知道：215→216 那次编辑的唯一功能 = 把佐藤从第四格挪出去。纸 = 说明书（教模运算下的乘法）本章被松枝识破，正式落地。
- 作者揣测：松枝"剔除"落笔、笔迹没有重也没有轻——作者用零修辞写全书最残忍的一笔。伊达直觉第二回合败给规则，结构性地预告：直觉对、规则错，而规则错在脚底下。

### ch19 双重
- 嫌疑人：不变。
- 机制：撤岗生效 → 佐藤退出全部视野。**类型确定性 100%：他死定了，且会死在撤岗后立刻。**
- 作者揣测：早川"接缝那半页您留着是对的"——凶手赞赏侦探的诚实声明，因为诚实声明恰是凶手的免罪符。记录18"覆盖率达预期"：谁的预期？设计者的。佐藤填捐赠验收单、"下周见"、布包带子勒出印——标准诀别镜头，作者在给读者发讣告预印本。

### ch20 样本外
- 嫌疑人：不变。
- 机制：佐藤死，撤岗到死亡 <2 天。机制全貌对读者完全透明：**编辑（ch3）→ 名单（ch10）→ 精化剔除（ch18）→ 撤岗（ch19）→ 死（ch20），每一环合法，每一环读者在场。**
- 作者揣测：记录19"归类：样本外事件"——书名题眼的字面化（样本外 = out-of-sample，过拟合的补集）。松枝"哪个佐藤"= 全书最疼的一句。读者此时未解项只剩：动机、三浦的确切角色、早川如何收束。

### ch21 帮凶
- 嫌疑人：不变。
- 机制：松枝用被改过的 216 重算三遍"剔除成立"——读者知道答案、知道他用错了数，本章悬念只剩"他什么时候去查原始库"。章末工作记录甩出四月清洗日志快照：作者开始把证据往松枝眼前推。
- 作者揣测："我是帮凶"是作者要的情感落点；本章对读者的信息增量 ≈ 0，节奏完全依赖情感。读者已进入等待期。

### ch22 策展
- 嫌疑人：不变。全查 → 唯一改动 215→216 → 215 mod 199 = 16 = 第四格。**对预备读者，这不是震撼，是 ch18 已完成的验算被松枝追认**——这就是作者不满①的结构根因（详见第二阶段）。
- 机制："改动先于条件 → 改动者必须预知条件 → 能预知的只有设计条件的人"。这一步在逻辑上其实已经点名，ch23 的排除法只剩形式补全。笔迹连线（祖母结 ↔ 板书同构："布置的人站在作品对面"）本章建立，漂亮但同样是确认。
- 作者揣测：章末记录21"他开始重算了"= 凶手俯瞰。作者把章末锤交给了工作记录而非正文——叙事层的收割开始。

### ch23 重演
- 嫌疑人：排除法三类 → 只剩早川。**读者在 ch14（95%）/ ch18（机制全透明）早已完成此排除；本章的全部价值是"松枝的认知追上读者"。** "机器看着呢"重读安放在排除法后段，位置正确。
- 机制：排除法的"预知条件"齿条公平且漂亮——全部依据读者在场材料（ch3 目击编辑、T+2、8/6 列席、其余顾问不经过 D）。
- 作者揣测：章末记录22"我等这一步，比等任何一笔成交都久"= 凶手掀底牌。戏剧反讽达峰。它对尚存疑的读者是盖章，对已确认的读者是 payoff——是设计好的收割，不是泄露。

### ch24 自白·上
- 嫌疑人：无（已无悬念）。
- 机制：早川承认到"是什么"层。记录23"旧档译注"= 凶手亲自给三条旧记录做旁注，等于作者替读者完成伏笔回收。
- 作者揣测："你查过每一把锁的来路。你来路的尽头是我，那一站你没有查"——全书题眼的另一句人话版。读者新获得：0。剩两个真问题：佐藤那笔账、动机。

### ch25 自白·下
- 机制兑现：佐藤 = 回执（"你的模型会杀人"）——与我 ch21 前后的猜测方向一致（"被理论判安全的人被杀"= 对理论的实证反例）。**三浦 = 桥、前两案执行者，与我 ch15 的"拆桥/灭口"猜测完全吻合。** 高野案侧门开锁补完 ch9 的 5/15 疑点。
- 动机：爆仓 + "市场惩罚运气差" + ABC 猜想/宇宙际理论往事。动机层超出读者可推范围（望月新一/Scholze 属外部知识彩蛋），但它不是免罪机制、只是人格注脚，公平性可接受。
- 作者揣测：记录24"监测脚本，今晚 24:00 停止运行"= 实验终止语。凶手用运维公告宣布自首。

### ch26 不拟合
- 机制：新空数据集截图 = 余韵/威胁：实验结束，下一个实验开始。"每一份递到手上的数据，先问它是谁整理的"= 松枝的疤。三辆红外套自行车 = 拟合冲动仍在，只是现在他知道它在开始。
- 作者揣测：结尾克制，点题不点名（"过拟合"三字始终不进正文，纪律合格）。

## 第二阶段：ch21–23 破解评估与修复方向审查

### Q1：现状破解评估

**（1）现在的排除法推进是否让早川在 ch23 之前就已暴露？**

是，但罪魁不是 ch23 的排除法。排除法本身的信息增量 ≈ 0：

- 对对抗性读者，早川在 ch14 已被叙事层证据锁定（工作记录的测量者口吻）；在 ch18 已被机制层证据锁定（215→16=第四格，编辑功能完全可算）；读者带着两年的确定性走进 ch21–23。
- 更关键的是 **ch22 内部已完成实质点名**："改动先于条件 → 改动者必须预知条件 → 能预知的只有安排条件的人"。这条齿条一落，能编辑的人里只剩"知道轨道会存在的人"——= 规则之外的机器放置者 = 凶手本人。ch23 的三类人排除（流程持有人/技术人员/自己）只是把这个已完成的结论翻译成花名册语言。读者在 ch22 结尾就翻完了 ch23 的最后一页。
- 也就是说：**现状下 ch21–23 是"松枝追上读者"的三章**。这个结构本身可以成立（倒叙侦探的第二幕就该这么写），成立的前提是这三章提供程序之外的东西——松枝的承受。现状提供的几乎全是程序（重算三遍、全查、排除法），所以读起来冷。作者的两条不满指向同一处，不是泄露问题。

**（2）章末"他开始重算了"/"我等这一步"是否反而帮读者确认？**

是，明确帮确认——记录21 把凶手的视线明示（他看着松枝调阅、重算），记录22 干脆是凶手第一人称的预告。对尚存疑的读者，这是作者亲手盖章；对已确认的读者，这是反讽 payoff。

但要定性准确：这是**设计好的收割，不是泄露事故**。真正的泄露（如果算泄露的话）发生在 ch3（编辑伏笔）、ch13（笔迹）、ch14（拟合速率）、ch18（数学可算）——全部在 ch21 之前。到 ch23 章末，读者里没有"还不确定的人"这两句可以伤害。

真正值得作者警惕的是配套问题：在硬约束"排除依据只许用读者在场材料"下，ch23 排除法把通往"别的人"的活路全部堵死（技术人员有周报对账、其余顾问不经过 D、链外要过机房门），于是章末两句**只能做"确认"，做不了"揭晓"**。若想让它们重获揭晓功能，唯一办法是删弱 ch22 的"预知条件"齿条或给排除法留一条活路——**我不建议**：那条齿条是全书最公平、最漂亮的一步推理，为它牺牲两处章末反讽的纯度是亏本买卖。结论：接受"确认"定位，把张力从"是谁"转移到"松枝如何承受这个是谁"——这正是修复方向 b/c 的用武之地。

附带一个时点诊断：ch21 章末工作记录甩出四月清洗日志快照（215→216 前后两版），等于作者已经替读者把锤举起来了。ch22 的"发现编辑"因此天然带着"程序必然性"——这是作者不满①的技术根因之一，另一半根因是 ch18 的数学公平性提前预支了震撼（见下）。

### Q2：四个候选修复方向的提前破解风险评估

#### 方向 a：加强 ch22"发现编辑"的震撼呈现（放慢、给物件承重、停顿）

- **会不会让早川提前暴露？** 增量低（读者 ch14 已锁定），但有**章内压缩风险**：放慢 + 承重 = 把"改动者是谁"的思考时间也一并给了读者。读者会在 ch22 内部就完成"编辑者=早川"的并案，ch23 排除法彻底沦为流程宣读。**风险评级：中。**
- **会不会让"佐藤第四格"提前可算？** 零增量——ch18 已可算，ch20 已类型确认。评级：低。
- **"挣扎与开脱"维度**：本方向不涉及。
- **降低风险的具体条件**：
  1. **锤的落点必须对准伤口，不对准凶手**。震撼段的情感主语是"佐藤本来在第四格 / 理论没有漏 / 是我把他挪走的"，不是"那一秒 / 那双手"。现文里"多停了一秒"的三处呼应（ch3/ch22/ch23）要守住分工：ch22 那处停在"我目击了它并且签过字"，把"签字的是谁"留给 ch23 开头再翻。
  2. **物件承重给佐藤侧，不给编辑动作侧**。该被放慢的是镇纸、验收单、隔布料按一下的名片（佐藤留在世上的重量），不是光标、键盘、日志（凶手的指纹）。前者加深 dread，后者直接是指控场景。
  3. **停顿用在"215，在。216，不在。"之后，不停在"谁改的"之前。** 锚点句之后的停顿让读者消化的是"佐藤从未出局"这个事实的残忍；若在"谁"上停顿，等于作者替读者举手提问，ch23 无题可开。
  4. 底线自测：如果震撼段写完后，一个 ch18 没算过数的普通读者也能在 ch22 内说出"是早川"，就越界了；合格线是他只能说出"佐藤是被 design 出去的"。

#### 方向 b：ch22–23 加入松枝"为早川开脱"的内心挣扎段（调用前文既有异常细节）

- **会不会反而给读者递答案？** 会，有中度风险。挣扎若表现为**异常清单的枚举**，等于把散在 ch3/13/14/17/19 的伏笔汇编成起诉书：慢读者在此被正式剧透，快读者觉得冗余（他们 ch14 就编完这份清单了）。**风险评级：中。**
- **会不会让早川提前暴露？** 中——但注意基线：读者早已暴露完毕，此方向的真实风险不是"告诉读者是谁"，而是**把"松枝还不知道是谁"的可信度写崩**。若挣扎段引用太多指向性异常，读者会反问"他都想到这一步了还不明白？"——人物信誉受损比剧透更贵。
- **会不会让"佐藤第四格"提前可算？** 无增量。评级：低。
- **降低风险的具体条件**：
  1. **每条开脱必须具体且可证伪，死法只用读者在场材料**。"也许是技术人员动的"→ 被周报逐条对账杀死；"也许有第五类人"→ 被流通链登记杀死；"也许四月没人知道轨道会被用上"→ 被"改动先于条件"杀死。严禁"也许是我搞错了轨道"这类不可证伪的虚晃——那会误伤已建立的理论可信度，而理论可信是全书地基。
  2. **异常细节的调用必须挂在开脱的尸体上逐条引出**（挣扎→失败→异常浮起），禁止开列清单。每条异常进场的理由必须是"这条开脱死了，它浮上来"，不是"作者觉得该回收伏笔了"。
  3. **位置：嵌进 ch23 排除法之中，而不是排除法之后的完整独白。** 每排除一类人，松枝试着把早川塞进那个类别里、再失败——挣扎与排除同步推进。若先排除完、剩下名字、再补一段不舍独白，等于先公布答案再表演挣扎，顺序倒置，必假。
  4. "希望不是他"的偏好**只登记一次**（现文"记在心里那页专门登记偏好的纸上"的装置很好，保留单次，勿复读）。
  5. 遵守情绪不点名纪律：挣扎用动作和判断写（重算、换算法、从头再核一遍），不用心理形容词写。

#### 方向 c：把 ch23 排除法改成有对手/有场景张力的一场戏

- **会不会让早川提前暴露？** 低-中。换容器不换信息——排除法的内容不变，读者的信息集不变。但有两个具体风险：①对手若说出名字=提前引爆；②**伊达在 ch22 已说过"数据不是早川先生管的吗"**——戏里伊达天然会先指向数据侧，必须管住他的嘴，否则他的名字会比松枝的先落地，人物顺序错乱。**风险评级：低-中（四方向中最低）。**
- **会不会让"佐藤第四格"提前可算？** 无增量。评级：低。
- **降低风险的具体条件**：
  1. **对手（建议伊达）的职责是替流程辩护、替早川辩护**——把方向 b 的"开脱"外化成对手台词。这比纯内心独白更戏剧、更省篇幅，且符合伊达"后背发紧但上不了卷宗"的既定位置。b+c 组合是最优解。
  2. **名字只能由松枝、在戏的终点、以"操作上只剩这一个名字，必须去验证他"的形式说出**——守住真相纪律（排除法给不出"是他"）。对手全程不许说"是早川""你的搭档"这类定性词。
  3. **场景张力的来源放在 stakes，不放在"猜是谁"**：移交时限、林的特级布防还在跑、佐藤的账没人认、并案标准第一条是松枝自己写的——这些现成材料足够撑一场戏的张力，无需动用悬念。
  4. 副作用须知：戏会让"只剩一个名字"更响亮，ch23 章末两句的确认功能被进一步压缩成纯反讽——可接受（见 Q1 结论），但别再给章末加戏。
  5. 禁用词纪律下，场景戏比独白更容易情绪外溢：用物件承重（白板、三份重演稿、聘任记录、伊达那张便签），不用语气承重。

#### 方向 d：提前/加重"其他异常"（ch13 笔迹、ch14"机器看着呢"、ch19"接缝那半页"、工作记录批注口吻等）在 ch21–23 的召回密度

- **会不会让早川提前暴露？** 会，且是四方向中唯一实质改变读者信息集的方向。**风险评级：高。** 这些异常每一条单独都是签名级证据：笔迹"横平竖直"↔板书、 "机器看着呢"= 他自己就是机器、"接缝那半页留着是对的"= 他看着侦探的诚实声明（而诚实声明是他的免罪符）、"他的拟合速率高于预期"= POV 级铁证（测量者口吻）。密集召回 = 在揭晓前给读者发答案汇编。尤其"拟合速率"一句，一旦在 ch21–22 被重读，排除法之外又多一层叙事层铁证，ch23 与 ch24 双双贬值。
- **会不会让"佐藤第四格"提前可算？** 无关（第四格的可算性由 ch3+ch18 的数字决定，与这些异常无关）。评级：低。
- **降低风险的具体条件**：
  1. **ch21–22 只许使用 ch22 正文已建立的笔迹连线**（祖母结↔板书同构，"布置的人站在作品对面"），不新增异常召回。
  2. **"机器看着呢"重读维持现位**（ch23 排除法后段、合法接触+能力核完之后）——现文这个位置是对的，勿提前。
  3. **"他的拟合速率高于预期"的首次重读必须留给 ch24 对峙**——现文处理正确，它是工作记录谜底的总开关，提前一天都是事故。
  4. **工作记录口吻的系统性重读只能发生在 ch24 之后**（现文 ch24/26 的处理正确）。ch21–23 里工作记录只允许以"章末锤"的单句形式出现（"他开始重算了""我等这一步"），不许被松枝在正文里翻检。
  5. "接缝那半页"可在 ch23 出现一次，但功能是道德性的（他看着我保留诚实声明 = 他看着我的每一步），不许写成证据性的。
  6. 总原则：**召回密度上限 = 每条一次、各就各位**。这本书的伏笔系统本来就是"全在明处、读者自取"的公平设计；ch21–23 的工作不是加密度，而是让松枝在正确的时间走到读者早已站着的那些位置。超过上限，公平设计就变成作者下场作弊。

## 总评

1. **ch21–23 的病不在泄露，在增量类型**。泄露（如果坚持用这个框架）在 ch3/13/14/18 已完成，且多半是作者主动的设计（工作记录文体、横平竖直、拟合速率）。到 ch21 读者要的不是信息，是松枝的承受。三章给程序不给承受，所以冷。
2. **四个方向的取舍**：c（对手戏，低-中）+ b（挣扎，中，嵌进排除法）组合是最优解，两者天然互补（b 的内心开脱外化为 c 的对手辩护）；a 重定向后可用（锤对准佐藤侧，不对准编辑者侧）；**d 应弃用或严格限流**，它是唯一会造成真实信息泄露的方向。
3. **两个必须保住的资产**：ch22 的"改动先于条件→预知条件"齿条（全书最公平的一步推理，别为震撼牺牲它）；真相纪律"排除法只给得出必须去验证他"（它保住了 ch24 对峙的存在理由）。
4. **一个作者的认知校准**：作者不满①（"发现编辑震撼不够"）的深层原因是 ch18 把这道题的答案用公平线索全给了读者——这不是 ch22 的失误，是本格公平性的代价，且是这本书最体面的代价。修复方向不该是"让震撼更响"（程序性的东西放再大也响不过读者自己的验算），而是"让震撼更疼"：锤落点从"数据被策展"移到"佐藤从未出局，是我亲手把他挪走的"。疼是读者的验算预支不了的。
