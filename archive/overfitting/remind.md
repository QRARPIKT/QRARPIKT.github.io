4. 打包听令：「你不用每次改完重新打包。在我要求之后再打。」
5. 不设字数上下限（「别带字数限制带，先发挥，到时候改是啥是啥」）。
6. DR-01：「过拟合」三个字永远不得出现在任何章节正文。

## 二、每轮改动的标准流程（不可跳步）

1. 改前快照：`cp chapters/chNN.md → phase2_swarm/old_versions_v2/oldNN_rMM.md`
2. rep() 精确替换并断言计数：
   `def rep(t, old, new, cnt=1): c=t.count(old); assert c==cnt,(c,cnt,old[:40]); return t.replace(old,new,cnt)`
   **内核经常重置，每个 cell 开头重定义 rep/w/pathlib/re/subprocess/shutil。**
3. **写后读回（w() 强制，轮72/73 分叉事故后立）**：
   `def w(p, t): pathlib.Path(p).write_text(t, encoding='utf-8'); assert pathlib.Path(p).read_text(encoding='utf-8') == t`
   教训：报 `internal: ssh: unexpected packet` 的 cell 可能在分叉实例上执行——探针会骗你（在分叉上通过），回读最终文件不会。
4. `python3 verify_probes.py`（cwd=/mnt/agents/output/guonihe），必须 26 PASS 0 FAIL。
5. 重建 final：`'

'.join(26章strip)+'
'` → final.md；final.txt = 标题行去掉 `# ` 前缀。
6. 轮次登记：build_diff_page_v3.py 顶部 `ROUNDS = [` 后**头部插入**（一章一条：`("轮 MM", "chNN#oldNN_rMM", "摘要")`），跑之生成 rounds_v3.html；再跑 build_final8_page.py 生成 index.html。
7. `website_version_manager` build_version，type=html，project_dir=/mnt/agents/output/app，message 简短。
8. 例外：用户明说「不用 vimdiff」的轮次（如轮83 双空行统一）只做快照＋落盘＋final 重建，不登记不建站。
9. truth.md＝正文事实的唯一事实源（时间线/数值/线索台账）；正文轮次若动到这些，先提案、用户批准后回写 truth.md（最近回写=R-27）。

## 三、文风禁令清单（用户历次裁定汇总，新写文字必须遵守）

**绝对禁词**：仿佛／微微／不由自主／一丝／不易察觉／某种／良久／许久／很久（全书清零，可用半晌或环境描写替代）；单字「核」（复合词可：核对/核验/验算/复核/核实/验证）；「过拟合」三字（DR-01）。
**句式修辞**：金句腔（含伪口语）；对仗、排比、短句铺列表演；冒号清单；破折号（全书不用）；「不是X，是Y」每章至多一处承重；成语式情绪标注（"心猛地揪紧了""不寒而栗"）新写文字不许出现；无谓语名词裸句只能当稀疏的氛围节拍，碎句堆里不许再用；碎句/流水账/防御性编程式叙述（「你是在写小说，不是防御性编程，也不是记录流水账」）；段尾评论腔、复述前文、把一句话说两遍；「这件事」等回指；「第二天一早」式时间开头；时间词每段开头泛滥；半句用句号切碎（「你咋那么爱半句用句号」）。
**重复禁令**：同一短句/句式不许跨章复用；同一信息不许在相邻章重复叙述；不许重复演读者已看过的戏。
**标点口径**：出口的问句一律带「？」（松枝问句必须问号）；内心独白设问用句号（冷题设装置："谁。""理论哪儿漏了。"）；逗号优先、慎用分号；全书统一单空行分段（双空行禁用，轮83）。
**表达边界**：排除法里"路"可死活、"一类人"不可；推测要写明"像是/似乎是"，不许陈述得像既定事实；抽象指称要具体化（"转岗造成的职工号变动"）。
**结构节奏**：开场不堆定语、不露坐标、名词直进；章末不用主角姓名收尾；辅线要经营；删大于加；换气章允许存在。
**人物声口**：松枝冷克制但问句带问号；早川公文式扁平是人设（有温度曲线）；伊达要有语气词（咯/吧/吗）；各人过去除公文框架外不露。
