五、三键机制白话图解

签名规则 R 有两层：签名物（事后布设，演戏挑衅）与目标选择函数（事前运行，决定谁死）。两层功能独立，但目标键的参数由签名物携带发布——松枝（和读者）因此误读为同一套规则。这个误读本身就是 overfit。

键 m（主键：谁进来）

  • 条件：m % 165 == 0。165 = E2 签名数列（3、7、21、49 = n 个交叉点下的素纽结数，OEIS A002863）的下一项 a(10)。
  • m 映射自学籍号（三位旧档号，旧系统字段）。
  • 实算存档：中村 m=165（=165×1，序列下一项即第一死者编号）、高野 m=990（=165×6）、白川 m=330、林 m=495、小島 m=660、佐藤 m=825——1000 以内 165 的倍数恰 6 个，全部命中。
  • 白话：把数据集 D（中村研究室轨道关联人员）里每个人的学籍号除以 165，余数为 0 的进目标集合 S。参数 165 由上一案的签名数列向前发布（3、7、21、49 的下一项）——签名物不仅签名，还在发布下一把锁的钥匙。

键 t（序键：谁先死）

  • 定义：候选人下一个已确定的学术关联日程（会议开幕/访问/截止），含已定但未发生的日程；t 升序 = 谁先死。
  • 这就是佐藤排 7/5 的原因：他转岗后仍被邀请研究室年会（7/5，周日），普通人的温情人脉成了排序字段。
  • 实算：白川 6/19（东京会议开幕）< 林 6/27（理事会）< 小島 7/2（筹备会）< 佐藤 7/5（年会）→ 第一次预测=白川（ch12）。
  • 白话：把 S 里的人按「下一个学术日程」从早到晚排序，排最前的就是下一个目标。第一次排序的输出是白川（6/19）——这就是 ch12 第一次预测的来源。

轨道键（E3 后的「精化」，199 案）

  • 来源（199 案）：E3 白板上的退化三次曲线 y² = x³ − 6x − 80（mod 199）（Δ≡0，结点 (179,0)，光滑点群 ≅ F₁₉₉*）与标记点 M=(97,81)（t(M)=2 ⟹ t(nM)=2ⁿ）；方法由 E4 纸面携带（mod 165 的"乘二绕回"，第 44 项=16）。
  • 条件：职工号 mod 199 的余数 ∈ 轨道 {x(nM)} = {97, 6, 152, 16, 42, 110, …}（格 1–6）；佐藤 216→17 处无点（f(17)≡154 为二次非剩余），出局。

215 → 216：一个字段一个单位如何挪走佐藤

四月清洗期，佐藤的职员编号在旧系统记 215、现属系统记 216（转岗迁移末位错一位，每个大学人事档案都有的脏数据）。早川「以现属系统为准」把 215 改成 216——两个都是真值，理由齐全，日志留痕，松枝当场目击并认可。四个月后的 8/5 夜，松枝解出轨道；8/6 会议上，216→17 处无点 → 「佐藤実，剔除」→ 8/7 撤岗生效 → 8/8 夜死。

  • 四月：编辑发生，215 → 216。
  • 八月：216 mod 199 = 17，x=17 处无点 → 剔除。
  • 重算（ch22–23）：215 mod 199 = 16 = x(4M) = 第四格 → 佐藤从未出局；且第四格本来就是他的——松枝 8/5 夜填进第四格的三浦，是填在佐藤头上。

改动先于条件（但裸时间锁不足为凭——曲线可围着既有号码造，数据→曲线方向天然成立，R-19 修正）：真正的锁在数里。第四格=215 的余数、无点处=216 的余数，曲线围着这一对数造；215 只躺在四月封存的原始件与清洗日志里，知道这一对数的人名单极短。重读要点：松枝的错不在逻辑，在他用的数据集；而轨道键的引入（成本之问→那张纸→方法移植）每一步读者都能跟着算，正是凶手设计好等他踩的 overfit 展示；E4 纸的答案 16 就是佐藤本来的格子——说明书递到他手上，他拿它填了三浦。
